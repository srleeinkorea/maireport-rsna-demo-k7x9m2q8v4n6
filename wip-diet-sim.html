식이 질문·목표 검증

설계 기준 시뮬레이터 — MaiReport Admin 「식이 질문·목표 검증」과 같은 화면이지만, 서버 없이 데이터계약 규칙을 이 브라우저 안에서 계산해요. 펼치면 검증 서버와 다른 점이 보여요.
  • 문구·질문·선택지는 데이터계약 원본(SharePoint, 2026-10-08 수정본 · 목표 문구 176건) 기준이에요. 반영 여부는 「시뮬레이터 QA 체크리스트」 메뉴에서 확인해요. 검증 서버 데이터(1.0.1, 143건)보다 최신이에요.
  • 단계 올리기는 2026-10-07 설계 변경(그 축의 끝난 목표 최근 4건 중 3건 완료, 3건 미만이면 판단 안 함)으로 계산해요. 내리기는 2건 연속 미완료예요.
  • 그날 질문 축에 통과 문구가 없으면 직접 선택 연결 축 → 일반 축 순서로 내려가 문구를 찾아요. 그래도 없을 때만 「안내만」이에요.
  • 같은 축을 3일 연속 물었으면 다음 날은 다른 축을 물어요(설정 CFG-018).
  • 가정으로 둔 것: 일반 축 안에서는 축을 가리지 않고 최근 30일에 안 나온 문구를 번호 순으로 고름 · 17시 이후와 새벽의 「조금 적게」는 식후 가능 문구만 사용(회복 문구는 식후 가능이 아니라 빠짐) · 새벽(00~04시)에는 식후 가능 문구 중 시간 표시가 「저녁」인 2개만 사용 · 「거의 못 먹거나 거름」으로 회전 질문이 없는 날의 질문 축은 끼니 규칙.
  • 「다음날 질문」에서 며칠 쉬고 접속하는 경우를 만들 수 있어요(검증 서버 화면에는 없는 기능). 쉰 날에는 질문도 목표도 만들어지지 않아요.
  • 넣을 수 없는 것: 진료정보 질환 확인, 검진 결과, 수면(부담 줄이기 목표), 명절·연휴 날짜. 검증 서버 화면과 같아요.
  • 가상 사용자는 이 브라우저에만 저장돼요. 다른 사람이나 다른 기기에서는 보이지 않아요.
검증 서버 기록 — MaiReport Admin 검증 서버(데이터 1.0.1)에서 만든 가상 사용자 기록을 그대로 담은 읽기 전용 화면이에요. 목록에 5페이지 제한이 없어요.
