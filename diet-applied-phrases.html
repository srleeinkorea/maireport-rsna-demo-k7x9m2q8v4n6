개별 검토 (선택) ↓

개별 문구를 열지 않고 등록된 전체 목표·이유 문구를 한 번에 검토하고, 6가지 기준별 판정과 수정 제안을 표에서 일괄 편집·저장합니다.

규칙 기반 일괄 검토는 모든 문구를 처리하지만 의미·임상적 적정성을 자동으로 확정하지 않습니다. 의미 기반 AI 심사를 하려면 아래 요청서·결과 가져오기 기능을 활용하세요. AI 결과 역시 최종 의학적 승인과 구분됩니다.

배포된 데이터의 로딩이 끝나면 일괄 검토를 시작할 수 있습니다.

개별 문구 상세 검토 (선택)

문구 목록으로 ↑

전체 목표·이유 문구를 한 번에 예비 점검하고, 표시된 검토 후보를 6가지 기준으로 개별 확인합니다.

자동 점검은 표현 규칙에 따른 확인 후보이며 AI의 전문가 판정이 아닙니다. 의학적 근거·개인별 권고 적정성은 별도로 확인해 주세요.

문구 데이터를 불러오면 검토를 시작할 수 있습니다. 불러오기에 실패했다면 위의 ‘다시 불러오기’를 이용해 주세요.

전체 문구 일괄 적절성 예비 점검

등록된 모든 목표·이유 문구의 표현, 맥락 데이터, 근거 확인 상태를 한 번에 확인합니다. 기존 수동 검토 기록과 배포 원문은 바꾸지 않습니다.

전체 문구 점검 결과 · 비교표

일괄 점검 후 우선 확인 대상과 확인 사유를 비교하고, 개별 검토로 바로 이동할 수 있습니다.

문구 ID / 수동 검토목표 · 이유 원문자동 예비 점검 · 확인 사유저장된 수정 제안작업

자동 예비 점검은 규칙 기반 확인 후보입니다. ‘규칙상 신호 없음’도 적절함 판정이 아닙니다. 개인별 적합성·의학적 근거는 전문가가 추가 검토해야 하며, 승인 결과를 일괄 생성하지 않습니다.

현재 적용 문구

자동 점검 · 확인할 표현

1. 기준별로 직접 검토해 주세요

2. 수정안을 작성하고 비교해 주세요

수정안 미리보기

문구 비교용 미리보기입니다. 실제 앱의 줄바꿈과 노출 조건은 별도로 확인합니다.

3. 검토 판정을 남겨 주세요

‘적절함’은 6가지 기준을 모두 확인해야 저장됩니다. ‘수정 필요’·‘추가 확인’은 의견을 함께 남겨 주세요. 수정 제안이 있다면 판정은 제안 반영 전의 현재 적용 문구를 기준으로 합니다.

검토 기록은 이 기기·브라우저에 저장됩니다. 팀과 자동 공유되지 않으며, 브라우저 데이터를 지우면 사라질 수 있습니다. 문구를 바꾸기 전에 저장해 주세요. CSV로 내려받아 공유할 수 있습니다. 원문 반영은 원본 데이터 수정 후 별도로 진행합니다.
